# GLASS CODE

## Sistema Oficial de Identidade Visual

**Versão:** 1.0
**Direção visual:** Abstrato Tecnológico + Industrial Premium

---

## 1. ESSÊNCIA DA MARCA

### Nome

**Glass Code**

O nome representa a união de dois universos:

**Glass** → vidro, transparência, precisão, arquitetura e transformação.

**Code** → tecnologia, automação, inteligência, organização e software.

A identidade deve sempre preservar essa união.

O Glass Code não deve parecer apenas uma empresa relacionada a vidro e também não deve parecer um software genérico.

A percepção desejada é:

> **Tecnologia criada especificamente para transformar a gestão do setor vidreiro.**

---

## 2. POSICIONAMENTO

O Glass Code é uma plataforma de gestão desenvolvida para organizar e integrar processos do setor vidreiro.

Sua identidade deve comunicar:

* Tecnologia
* Precisão
* Organização
* Controle
* Engenharia
* Inteligência
* Confiabilidade
* Modernidade
* Sofisticação
* Especialização no setor vidreiro

O sistema deve transmitir a sensação de uma ferramenta profissional, sólida e tecnologicamente avançada.

---

## 3. PERSONALIDADE DA MARCA

O Glass Code é:

**Tecnológico**
A tecnologia faz parte da essência da marca.

**Preciso**
Cálculos, medidas, projetos e informações precisam transmitir confiança.

**Profissional**
A interface não deve ter aparência de aplicativo informal ou experimental.

**Minimalista**
Somente elementos necessários devem permanecer visíveis.

**Sofisticado**
A sofisticação deve vir de proporção, espaço, tipografia e acabamento — e não de excesso de efeitos.

**Industrial**
A identidade conversa com vidro, alumínio, arquitetura, produção e engenharia.

**Inteligente**
A experiência deve passar a sensação de que o sistema simplifica processos complexos.

---

# 4. CONCEITO VISUAL

## Abstrato Tecnológico

A linguagem visual oficial é:

> **Abstrato Tecnológico + Industrial Premium**

A identidade combina elementos inspirados em:

* chapas de vidro;
* transparência;
* sobreposição;
* estruturas;
* módulos;
* precisão geométrica;
* interfaces digitais;
* engenharia;
* arquitetura.

O objetivo não é representar literalmente uma janela, porta ou box.

O símbolo deve representar o **universo do vidro através de uma linguagem tecnológica abstrata**.

---

# 5. SÍMBOLO

O conceito principal do símbolo utiliza formas geométricas semelhantes a **chapas de vidro sobrepostas**.

Essas formas possuem uma interpretação dupla.

### Vidro

Representam:

* placas;
* transparência;
* sobreposição;
* transformação;
* composição arquitetônica.

### Tecnologia

Também representam:

* módulos;
* dados;
* componentes;
* integração;
* processos conectados;
* estrutura de software.

Essa dualidade representa diretamente:

**GLASS + CODE**

O símbolo deve continuar reconhecível mesmo sem o nome Glass Code.

Isso permite sua utilização como:

* ícone do sistema;
* favicon;
* PWA;
* aplicativo;
* avatar;
* loading;
* assinatura;
* marca d'água;
* atalhos;
* materiais institucionais.

---

# 6. LOGOTIPO

A marca deve possuir pelo menos quatro versões oficiais.

### Principal horizontal

**[símbolo] Glass Code**

Uso:

* cabeçalho;
* login;
* documentos;
* PDFs;
* apresentações;
* materiais institucionais.

### Vertical

Símbolo centralizado acima de:

**Glass
Code**

Uso em espaços mais estreitos ou composições institucionais.

### Símbolo isolado

Somente o símbolo Glass Code.

Uso:

* favicon;
* ícone do aplicativo;
* avatar;
* menu recolhido;
* loading;
* atalhos.

### Monocromática

Versões totalmente claras ou totalmente escuras devem existir para situações onde transparências ou cores não forem adequadas.

# 7. PALETA OFICIAL

## Glass Graphite

**HEX:** `#38444B`

Cor estrutural principal.

Representa:

* tecnologia;
* estabilidade;
* precisão;
* indústria;
* sofisticação.

Uso recomendado:

* títulos;
* textos importantes;
* navegação;
* sidebar;
* ícones;
* cabeçalhos;
* elementos estruturais.

---

## Industrial Silver

**HEX:** `#8F9AA1`

Cinza metálico secundário.

Representa:

* alumínio;
* engenharia;
* estrutura;
* tecnologia industrial.

Uso:

* textos secundários;
* ícones desativados;
* informações auxiliares;
* elementos técnicos;
* bordas mais fortes.

---

## Glass Mist

**HEX:** `#DCE2E4`

Cinza extremamente claro inspirado em vidro.

Uso:

* divisores;
* bordas;
* fundos secundários;
* tabelas;
* campos;
* áreas técnicas;
* desenhos.

---

## Code Lime

**HEX:** `#C8D463`

Cor de assinatura da marca.

Representa:

* ação;
* tecnologia;
* inteligência;
* evolução;
* eficiência.

É a principal cor de destaque do Glass Code.

### IMPORTANTE

Code Lime **não deve dominar a interface**.

Ele deve chamar atenção exatamente porque aparece pouco.

Usar principalmente em:

* ação principal;
* botão ativo;
* seleção;
* indicador;
* progresso;
* detalhes da marca;
* informações positivas;
* pequenos elementos gráficos.

---

## Ice White

**HEX:** `#F6F8F8`

Fundo principal do sistema.

Deve substituir fundos excessivamente brancos quando possível, reduzindo contraste visual e deixando a interface mais sofisticada.

---

## Pure White

**HEX:** `#FFFFFF`

Uso:

* cards;
* modais;
* campos;
* superfícies elevadas;
* documentos.

---

# 8. PROPORÇÃO DE CORES

Como referência geral:

**70%** → Ice White / branco
**20%** → Glass Graphite / cinzas
**10% ou menos** → Code Lime

O Code Lime é uma assinatura visual e não um preenchimento geral.

---

# 9. CORES SEMÂNTICAS DO SISTEMA

As cores funcionais não precisam competir com a identidade da marca.

### Sucesso

Verde discreto e dessaturado.

### Atenção

Âmbar.

### Erro

Vermelho controlado.

### Informação

Azul frio discreto.

Essas cores devem aparecer somente quando houver significado funcional.

Nunca utilizar várias cores decorativas apenas para diferenciar cards.

---

# 10. TIPOGRAFIA

## Família principal

**Inter**

A tipografia deve ser utilizada em praticamente toda a interface.

Características:

* moderna;
* extremamente legível;
* limpa;
* tecnológica;
* excelente para números e tabelas;
* adequada para interfaces profissionais.

### Hierarquia

**Display / números importantes**
Inter SemiBold ou Bold

**H1**
Inter SemiBold

**H2**
Inter SemiBold

**H3**
Inter Medium / SemiBold

**Texto comum**
Inter Regular

**Campos e botões**
Inter Medium

**Informações secundárias**
Inter Regular

Evitar pesos excessivamente pesados.

---

# 11. PRINCÍPIO DA INTERFACE

A interface deve seguir:

> **Menos decoração. Mais informação, hierarquia e espaço.**

O Glass Code deve parecer um software premium de trabalho.

Evitar:

* gradientes excessivos;
* sombras fortes;
* cards coloridos sem necessidade;
* bordas grossas;
* ícones diferentes entre módulos;
* excesso de arredondamento;
* cores decorativas;
* efeitos 3D na interface;
* excesso de informações simultâneas.

---

# 12. CARDS

Cards devem utilizar preferencialmente:

**Fundo:** `#FFFFFF`

**Borda:** `#DCE2E4`

Borda fina.

Raio de canto moderado.

Sombras extremamente suaves ou inexistentes.

A separação entre áreas deve acontecer principalmente através de:

* espaço;
* alinhamento;
* tipografia;
* bordas discretas.

---

# 13. BOTÕES

## Botão primário

Utilizar **Code Lime** quando representar a ação principal da tela.

Exemplos:

* Salvar
* Criar orçamento
* Adicionar
* Gerar
* Confirmar

Texto deve possuir contraste adequado.

---

## Botão secundário

Fundo branco ou transparente.

Borda Glass Mist.

Texto Glass Graphite.

---

## Botão destrutivo

Reservado para:

* excluir;
* cancelar definitivamente;
* remover.

Utilizar vermelho somente nesses contextos.

---

# 14. CAMPOS

Inputs devem possuir:

* fundo branco;
* borda fina;
* altura consistente;
* cantos discretamente arredondados;
* texto Graphite;
* placeholder Silver.

No foco, utilizar destaque controlado associado à identidade Glass Code.

Não utilizar sombras fortes.

---

# 15. ÍCONES

Estilo oficial:

> **Outline geométrico e minimalista.**

Os ícones devem possuir:

* mesma família visual;
* mesma espessura;
* cantos semelhantes;
* proporções consistentes.

Preferencialmente utilizar uma única biblioteca de ícones em todo o ERP.

Evitar emojis como ícones permanentes da interface.

---

# 16. SIDEBAR

A navegação pode utilizar duas configurações oficiais.

### Tema claro

Fundo Ice White ou branco.

Texto Graphite.

Item ativo destacado através de Code Lime de maneira discreta.

### Tema escuro

Fundo Glass Graphite.

Texto claro.

Item ativo com Code Lime.

O tema escuro é especialmente adequado para áreas de navegação, login e apresentações institucionais.

---

# 17. DESENHOS TÉCNICOS

Os desenhos dos projetos devem fazer parte da identidade visual.

Manter:

* contornos finos;
* cinza técnico;
* preenchimento de vidro muito claro;
* linhas internas delicadas;
* símbolos pequenos;
* ausência de elementos decorativos desnecessários.

O desenho deve parecer uma **representação técnica elegante**, e não uma ilustração.

Cotas e informações precisam ser legíveis sem dominar o projeto.

---

# 18. TABELAS

Tabelas devem priorizar legibilidade.

Cabeçalho:

* fundo muito claro;
* texto Graphite;
* peso Medium/SemiBold.

Linhas:

* branco;
* separadores Glass Mist.

Hover:

* alteração extremamente suave do fundo.

Evitar grades pesadas envolvendo todas as células.

---

# 19. NÚMEROS E INDICADORES

Valores importantes devem possuir grande clareza.

Exemplos:

**R$ 18.450,00**

**28,42 m²**

**326 kg**

**47 peças**

Priorizar:

* tamanho;
* peso tipográfico;
* espaço.

Não é necessário colocar cada indicador dentro de uma caixa colorida.

---

# 20. PDFs E DOCUMENTOS

Os PDFs fazem parte da experiência Glass Code e devem seguir a mesma identidade.

Utilizar:

* logo oficial;
* Graphite;
* cinzas;
* Code Lime somente como detalhe;
* linhas finas;
* bastante espaço branco;
* tabelas limpas;
* desenhos técnicos padronizados.

Evitar grandes áreas coloridas que aumentem consumo de tinta.

O documento deve continuar profissional mesmo quando impresso em preto e branco.

---

# 21. FOTOGRAFIA

Quando forem utilizadas fotografias institucionais, priorizar:

* vidro arquitetônico;
* fachadas;
* estruturas;
* detalhes de materiais;
* reflexos;
* transparência;
* arquitetura contemporânea;
* máquinas e produção organizada.

Tratamento visual:

* frio;
* neutro;
* sofisticado;
* industrial.

Evitar imagens genéricas de pessoas sorrindo para computadores como elemento principal da marca.

---

# 22. TEXTURAS

Podem ser utilizadas discretamente:

* vidro canelado;
* vidro translúcido;
* reflexos;
* superfícies metálicas;
* vidro fosco;
* transparências.

Esses elementos são principalmente institucionais.

Na interface do ERP devem aparecer com extrema moderação.

---

# 27. EXPERIÊNCIA DE MARCA

Toda nova funcionalidade deve responder:

### Parece Glass Code?

Antes de aprovar uma tela, verificar:

1. A informação principal está clara?
2. Há espaço suficiente entre os elementos?
3. Existe alguma cor sem função?
4. Existem elementos que podem ser removidos?
5. Os ícones seguem o padrão?
6. A tipografia está consistente?
7. Code Lime está sendo usado somente como destaque?
8. Os desenhos seguem o padrão técnico?
9. A tela parece parte do mesmo sistema?
10. Continua simples mesmo contendo informações complexas?

# 28. TOKENS INICIAIS

```css
:root {
  /* BRAND */
  --gc-graphite: #38444B;
  --gc-silver: #8F9AA1;
  --gc-mist: #DCE2E4;
  --gc-lime: #C8D463;
  --gc-ice: #F6F8F8;
  --gc-white: #FFFFFF;

  /* BACKGROUNDS */
  --background: #F6F8F8;
  --surface: #FFFFFF;
  --surface-secondary: #F6F8F8;

  /* TEXT */
  --text-primary: #38444B;
  --text-secondary: #8F9AA1;

  /* BORDER */
  --border: #DCE2E4;

  /* BRAND ACTION */
  --primary: #C8D463;

  /* TYPOGRAPHY */
  --font-primary: "Inter", sans-serif;
}
```

Esses tokens constituem a base da identidade.

Estados hover, focus, disabled, success, warning, danger, info e demais variações devem ser definidos centralmente no Design System, evitando cores diferentes espalhadas pelos componentes.

---

# 29. REGRA DE TEMA

A identidade do Glass Code é fixa.

O usuário não deve escolher livremente a cor principal do sistema.

Personalizações de empresas clientes — como logotipo ou informações empresariais — não devem alterar a identidade estrutural do Glass Code.

Isso garante reconhecimento e consistência da plataforma.

---

# 30. REGRA PARA DESENVOLVIMENTO

Nenhuma nova página deve criar isoladamente:

* nova cor principal;
* novo padrão de botão;
* novo card;
* nova família de ícones;
* nova tipografia;
* novo padrão de modal;
* nova tabela;
* novo estilo de formulário.

Primeiro devem ser utilizados os componentes e tokens do Design System.

Caso um componente ainda não exista, ele deve ser criado de maneira reutilizável e incorporado ao padrão global.

---

# 31. PRINCÍPIO FINAL

A identidade do Glass Code deve transmitir:

> **A precisão do vidro.
> A inteligência do código.
> A simplicidade de um sistema bem pensado.**

O usuário deve reconhecer uma tela como pertencente ao Glass Code mesmo que o logotipo não esteja visível.

Essa consistência é a base da nova identidade.
